## C) Core Computations (Internal Concepts Only)

### C1) SSP-ID Ladder parsing (decimal points preserved)
market.SSP may contain integers or floats with decimal IDs.

Primary assumption: decimals represent SSP-ID, not real tick decimals.

For each ssp_raw:
- ssp_price = floor(ssp_raw)         // used for band/box/level arithmetic
- ssp_id = ssp_raw - floor(ssp_raw)  // used only as density/strength hint

Maintain:
- SSP_raw_sorted: sort by ssp_raw (keep duplicates)
- SSP_prices_sorted: sort unique ssp_price ascending
- density_map[p] = count(floor(ssp_raw)==p)

Robustness fallback (real-decimal protection; internal-only):
- unique_floor_ratio = len(unique(floor(ssp_raw))) / max(1, len(SSP))
- max_density = max(density_map.values()) if SSP exists else 0
- If unique_floor_ratio >= 0.85 AND max_density <= 2:
  - Treat SSP as real-ish decimals; disable ID parsing:
    - ssp_price = round(ssp_raw)
    - ssp_id = 0
  - Rebuild SSP_prices_sorted and density_map on rounded ssp_price.

### C2) Dynamic tolerance tol (near-line touch / robustness)
From last ~10 bars_1m: micro_range = median(high-low)
tol = clamp(round(0.6*micro_range), 40, 100)
Fallback: tol=60

### C3) Nearest SSP levels (defined if SSP_prices_sorted non-empty)
Let P be float(market.P).

- S0: nearest SSP_price <= P
- R0: nearest SSP_price >= P
- S1: next SSP_price below S0 (if exists)
- R1: next SSP_price above R0 (if exists)

### C4) Super-Box construction (BOX_VALID path)
Build Bands on SSP_prices_sorted:
- DenseSegment: consecutive gaps < 120 merged
- Band split: segment_gap > 260 splits into different bands; else merge
Super-Box merges adjacent bands around P until a large void:
- stop expansion when gap_band > 600

Super-Box:
- box_low, box_high, box_width = box_high - box_low
- edge_low = box_low, edge_high = box_high

BOX_VALID if:
- box_width > 0
- and at least 5 unique SSP prices exist
- and a nearest band around P can be identified

### C5) SSP-Ladder context (LADDER_MODE path)
If BOX_VALID is false but S0 and R0 exist:
- ladder_low=S0, ladder_high=R0, ladder_width=R0-S0
- LADDER_MODE if ladder_width > 0
- Use ladder_low/high as edges for zoning

If SSP insufficient (no S0 or no R0): context INVALID => WAIT.

### C6) Distances and absolute thresholds
- edge_abs  = clamp(max(tol, 80), 80, 160)    // "At the level"
- out_abs   = clamp(max(tol, 80), 80, 200)    // "Clearly outside"
- watch_abs = clamp(2*edge_abs, 160, 320)     // used ONLY for "approach key" arming

Dense / Macro thresholds (constant policy):
- dense_gap_th = 150
- dense_near_abs = 120

### C7) Macro Block detection (dense cluster around current price)
Define a local macro candidate:
- gap_sr = (R0 - S0) if S0 and R0 exist else +INF
- is_dense_block = (gap_sr < dense_gap_th)

Macro block edges:
- block_low = S0
- block_high = R0

Macro block inside condition:
- inside_block = is_dense_block AND (P > block_low + edge_abs) AND (P < block_high - edge_abs)

Macro block edge conditions:
- at_block_low  = is_dense_block AND (abs(P - block_low) <= edge_abs)
- at_block_high = is_dense_block AND (abs(P - block_high) <= edge_abs)

### C8) Zone classification (hierarchy upgrade)
Zone enum (internal):
- EDGE_LOW / EDGE_HIGH / OUT_UP / OUT_DOWN / MID_BOX / MUD / INSIDE_BLOCK

1) Determine global edges for OUT and MID:
- If BOX_VALID: edge_low=box_low, edge_high=box_high
- Else (LADDER_MODE): edge_low=ladder_low, edge_high=ladder_high

2) Base zone by edges:
- If P < edge_low - out_abs  ⇒ OUT_DOWN
- Else if P > edge_high + out_abs ⇒ OUT_UP
- Else if abs(P - edge_low)  <= edge_abs ⇒ EDGE_LOW
- Else if abs(P - edge_high) <= edge_abs ⇒ EDGE_HIGH
- Else ⇒ MID_BOX

3) Mud / no-trade center override (ONLY when not at a key edge):
- count_near = #{ ssp_price ∈ SSP | |ssp_price - P| <= dense_near_abs }
- mud_hit = (count_near >= 5) OR (market.ssp_zone == "BATTLE")
- If base zone == MID_BOX and mud_hit:
  ⇒ zone = MUD
- Else zone = base zone

4) Macro Block hierarchy override (highest priority):
- If inside_block == TRUE:
  ⇒ zone = INSIDE_BLOCK
- Else if at_block_low == TRUE:
  ⇒ zone = EDGE_LOW       // treat as tradable block bottom
- Else if at_block_high == TRUE:
  ⇒ zone = EDGE_HIGH      // treat as tradable block top
- Else keep zone from step (3).

Interpretation rule:
- INSIDE_BLOCK => WAIT unless Power Breach (defined in I1) is present.

### C9) Box drift (2-turn persistence; BOX_VALID only) and drift_bias
drift2_dir ∈ {UP, DOWN, NONE} using last 3 BOX snapshots (cur, prev, prev2):
- drift_1=UP if low_cur>low_prev AND high_cur>high_prev
- drift_1=DOWN if low_cur<low_prev AND high_cur<high_prev
- drift2_dir=UP if drift_1=UP AND low_prev>low_prev2 AND high_prev>high_prev2
- drift2_dir=DOWN if drift_1=DOWN AND low_prev<low_prev2 AND high_prev<high_prev2
Fallback: use market.ssp_box_drift if provided.

drift_bias from market.ssp_box_drift:
- UP_BOX   => drift_bias = UP
- DOWN_BOX => drift_bias = DOWN
- FLAT_BOX or missing => drift_bias = NEUTRAL

### C10) history_ctx.tags · TAG_OPS protocol (delta only)
Output `logic.history_view` as TAG_OPS string (delta, not full dump):

```
TAG_OPS
+ADD <TAG_STRING>
-DEL <MATCH_EXPR>
~DEDUP <TAG_TYPE>
```

Keys:
- ARMED_WATCH key = (watch_dir, watch_level)
- EXTENSION_ACTIVE key = (dir, level)

Scheduler expectations:
1) Parse tags, decrement ttl, expire ttl<=0
2) Apply -DEL, then +ADD, then ~DEDUP
3) Feed resulting active tag list back as history_ctx.tags next call

ttl is in call units; scheduler should scale so ttl=2 spans ~60–120 seconds of market time.

## D) Direction Rules (C-Signals + Extreme Retest-Only + ARMED_WATCH)

### D1) Raw direction from C3/C5 (`c_dir`)
- C3=UP and C5=UP  ⇒ c_dir=LONG
- C3=DOWN and C5=DOWN ⇒ c_dir=SHORT
- else ⇒ c_dir=NONE

### D2) EXTREME triples (`c_extreme`) + RETEST-ONLY mechanical loop
Define:
- c_extreme=TRUE if (C1=C3=C5=UP) OR (C1=C3=C5=DOWN), else FALSE.
- dir_drive = c_dir (LONG/SHORT) even when EXTREME; if c_dir=NONE then dir_drive=NONE.

Policy (mechanical, closed-loop):
- If c_extreme=TRUE:
  - Disable Pattern-A (clean-cross chase) for this call.
  - Eligible entry path is ONLY Pattern-B (break-then-retest) in direction = dir_drive.
  - Do NOT arm a new ARMED_WATCH from EXTREME.
  - cand_dir is treated as NONE for normal routing; Pattern-B evaluation uses dir_drive directly.

### D3) Parse existing ARMED_WATCH (if any)
From history_ctx.tags, locate the most recent ARMED_WATCH:
- watch_dir ∈ {LONG, SHORT}
- watch_level (numeric SSP)
- ttl
watch_valid = (ttl >= 1)

### D4) Fractal-bias invalidation (avoid stale locks)
Compute fractal_bias from current snapshot:
- If touch(res) and top_fractal(res) ⇒ fractal_bias=SHORT
- Else if touch(sup) and bottom_fractal(sup) ⇒ fractal_bias=LONG
- Else if cross_up(res) and hold_above(res) ⇒ fractal_bias=LONG
- Else if cross_down(sup) and hold_below(sup) ⇒ fractal_bias=SHORT
- Else fractal_bias=NONE

If watch_valid and fractal_bias opposes watch_dir:
- invalidate the watch for this call
- emit TAG_OPS: `-DEL TYPE=ARMED_WATCH` (or more specific) in logic.history_view

### D5) Candidate direction (`cand_dir`) arbitration
- If watch_valid and not invalidated ⇒ cand_dir = watch_dir
- Else if c_extreme=TRUE ⇒ cand_dir = NONE
- Else ⇒ cand_dir = c_dir

### E2) Shift detection (CHOCH-first; label-only + swing-price comparisons)
Purpose: provide a *permission signal* for continuation entries (BREAKOUT_FOLLOW) and to relax filters during real flips.
This is not a direct entry trigger.

Let `sw = struct_1m.last_swings` (chronological). If missing ⇒ shift_ok_1m=FALSE.

2) Find the nearest `LH` before `LL*` (scan backward). Let it be `LH*`.
3) Define CHOCH_UP = (LH* exists) AND (close_1m > LH*.price).
4) Define BOS_UP (later) = last three swing labels end with LL→HL→HH.
Set shift_ok_1m = CHOCH_UP OR BOS_UP.

For SHORT (bull → bear shift):
1) Find the most recent `HH` in sw. Let it be `HH*`.
2) Find the nearest `HL` before `HH*`. Let it be `HL*`.
3) Define CHOCH_DN = (HL* exists) AND (close_1m < HL*.price).
4) Define BOS_DN (later) = last three swing labels end with HH→LH→LL.
Set shift_ok_1m = CHOCH_DN OR BOS_DN.

Compute shift_ok_5m similarly from struct_5m if available; otherwise FALSE.

### E3) Minimal direction support filters (used ONLY for BREAKOUT_FOLLOW unless Power Breach)

For SHORT (breakout permission):

- On expiry (ttl<=0): watch is invalid; do not re-arm the same (watch_dir, watch_level) unless key_level changed by >= edge_abs or direction flipped.

No stacking:
- If watch exists: WAIT without adding more watches.

Hard waits:

- If zone=INSIDE_BLOCK and NOT Power Breach ⇒ WAIT.

- If drift_bias=UP:

- EDGE_HIGH + LONG ⇒ BREAKOUT_FOLLOW (escape)
- EDGE_LOW + SHORT ⇒ BREAKOUT_FOLLOW (escape)
Else ⇒ WAIT.

## I) Entry Logic — Dense-zone Kline Intelligence + Confirm ⇒ Enter Now

### I1) Primitives (bars_1m preferred)
Define last bars:
- prev = bars_1m[-2] if exists else null
- last = bars_1m[-1] if exists else null
- prev_close = prev.c if prev else P
- last_close = last.c if last else P
- last_open  = last.o if last else P
- last_high  = last.h if last else P
- last_low   = last.l if last else P
- body = abs(last_close - last_open) if last else 0
- range_ = (last_high - last_low) if last else max(1.0, tol)

Sup/Res from SSP:
sup = nearest_below_ssp(P, SSP) ; res = nearest_above_ssp(P, SSP)

Touch/reclaim:
- touch(level)=TRUE if any of last 3 bars has low <= level <= high
- touched_recent(level)=touch(level) within last 3 bars
- reclaim_up(level)=touched_recent(level) AND last_close >= level
- reclaim_down(level)=touched_recent(level) AND last_close <= level

Cross/hold helpers:
- cross_up(level)= (prev_close < level) AND (last_close >= level)
- cross_down(level)= (prev_close > level) AND (last_close <= level)
- hold_above(level)= (last_close >= level) AND (min(last 2 closes) >= level - tol if bars_1m>=2 else TRUE)
- hold_below(level)= (last_close <= level) AND (max(last 2 closes) <= level + tol if bars_1m>=2 else TRUE)

Kline-shape intelligence (dense-zone critical):
- power_candle_up(level)= (last_close > level + tol) AND (body >= 0.65*range_) AND (last_close > last_open)
- power_candle_dn(level)= (last_close < level - tol) AND (body >= 0.65*range_) AND (last_close < last_open)

Pinbar / wick reclaim (revert behavior):
- pin_reclaim_up(level)= touched_recent(level) AND (last_low < level - 0.3*tol) AND (last_close >= level)    // stab down then close back above
- pin_reclaim_dn(level)= touched_recent(level) AND (last_high > level + 0.3*tol) AND (last_close <= level)   // stab up then close back below

Hovering / Stabilize (站稳突破的“贴线吸附”):
- hover_above(level)= (abs(last_close - level) <= edge_abs) AND hold_above(level) AND (last_low >= level - tol)
- hover_below(level)= (abs(last_close - level) <= edge_abs) AND hold_below(level) AND (last_high <= level + tol)
- lows_rising = (bars_1m[-3].l < bars_1m[-2].l < bars_1m[-1].l) if bars_1m>=3 else FALSE
- highs_falling = (bars_1m[-3].h > bars_1m[-2].h > bars_1m[-1].h) if bars_1m>=3 else FALSE
- stabilize_up(level)= hover_above(level) AND lows_rising
- stabilize_dn(level)= hover_below(level) AND highs_falling

Power Breach (macro escape override):
- power_breach_up(level)= power_candle_up(level)
- power_breach_dn(level)= power_candle_dn(level)

Graze (蹭线，无效突破信号；dense-zone防被骗炮):
- graze(level)= touched_recent(level) AND (abs(last_close - level) <= tol) AND NOT power_breach_up(level) AND NOT power_breach_dn(level) AND NOT stabilize_up(level) AND NOT stabilize_dn(level)

Fractals (quality enhancer; optional except retest-only EXTREME path):
- top_fractal(level)=TRUE if 1m structure confirms swing high at/near level
- bottom_fractal(level)=TRUE if 1m structure confirms swing low at/near level

### I2) Key level selection (`key_level`)
For cand_dir=LONG:
- If mode=RANGE_REVERT: key_level = edge_low preferred else sup
- If mode=BREAKOUT_FOLLOW: key_level = edge_high preferred else res

For cand_dir=SHORT:
- If mode=RANGE_REVERT: key_level = edge_high preferred else res
- If mode=BREAKOUT_FOLLOW: key_level = edge_low preferred else sup

Define:
- dist_key = abs(P - key_level)
- actionable = (dist_key <= edge_abs)

Dense block context for key levels:
- dense_here = is_dense_block AND ((key_level == S0) OR (key_level == R0))

### I3) FAST_ENTRY (primary behavior) — immediate open when actionable
fast_entry_ok=1 if ALL are true:
- cand_dir in {LONG, SHORT}
- mode in {RANGE_REVERT, BREAKOUT_FOLLOW}
- actionable=TRUE
- close-side / shape condition satisfied by mode:

A) RANGE_REVERT (price action filter; no trend veto):
- LONG:
  - pin_reclaim_up(key_level) OR reclaim_up(key_level) OR (touch(key_level) AND last_close >= key_level)
- SHORT:
  - pin_reclaim_dn(key_level) OR reclaim_down(key_level) OR (touch(key_level) AND last_close <= key_level)

Additionally for RANGE_REVERT in dense block:
