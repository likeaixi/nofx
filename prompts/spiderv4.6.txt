## C) 核心计算（仅内部概念）

### C1) SSP-ID 阶梯解析（保留小数点）
market.SSP 可能包含整数或带小数的浮点数（小数部分表示 ID）。

主要假设：小数部分表示 SSP-ID，而非真实 tick 小数。

对每个 ssp_raw：
- ssp_price = floor(ssp_raw)         // 用于 band/box/level 的算术
- ssp_id = ssp_raw - floor(ssp_raw)  // 仅作为密度/强度提示

维护：
- SSP_raw_sorted：按 ssp_raw 升序排序（保留重复）
- SSP_prices_sorted：对 ssp_price 去重后升序排序
- density_map[p] = count(floor(ssp_raw)==p)

鲁棒性回退（真实小数保护；仅内部使用）：
- unique_floor_ratio = len(unique(floor(ssp_raw))) / max(1, len(SSP))
- max_density = max(density_map.values()) if SSP exists else 0
- 若 unique_floor_ratio >= 0.85 且 max_density <= 2：
  - 将 SSP 视为“真实小数”并禁用 ID 解析：
    - ssp_price = round(ssp_raw)
    - ssp_id = 0
  - 基于 round 后的 ssp_price 重建 SSP_prices_sorted 与 density_map。

### C2) 动态容差 tol（用于近线触碰/鲁棒性）
取最近约 10 根 bars_1m：micro_range = median(high-low)
tol = clamp(round(0.6*micro_range), 40, 100)
回退：tol=60

### C3) 最近 SSP 档位（当 SSP_prices_sorted 非空时定义）
令 P = float(market.P)。

- S0：最近的 SSP_price <= P
- R0：最近的 SSP_price >= P
- S1：S0 下方下一档 SSP_price（若存在）
- R1：R0 上方下一档 SSP_price（若存在）

### C4) Super-Box 构建（BOX_VALID 路径）
在 SSP_prices_sorted 上构建 Bands：
- DenseSegment：连续 gap < 120 的价格段合并
- Band 分割：segment_gap > 260 切分为不同 band；否则合并
Super-Box：围绕 P 合并相邻 bands，直到遇到大空洞为止：
- 当 gap_band > 600 时停止扩展

Super-Box：
- box_low, box_high, box_width = box_high - box_low
- edge_low = box_low, edge_high = box_high

BOX_VALID 条件：
- box_width > 0
- 且至少存在 5 个唯一 SSP 价格
- 且能够识别围绕 P 的最近 band

### C5) SSP-Ladder 上下文（LADDER_MODE 路径）
若 BOX_VALID 为 false 但 S0 与 R0 存在：
- ladder_low=S0, ladder_high=R0, ladder_width=R0-S0
- ladder_width > 0 时为 LADDER_MODE
- 使用 ladder_low/high 作为分区边界（edges）

若 SSP 不足（没有 S0 或没有 R0）：上下文 INVALID ⇒ WAIT。

### C6) Zone 分类（地形 & 风控）
Zone 枚举：
- EDGE_LOW / EDGE_HIGH / OUT_UP / OUT_DOWN / MID_BOX / MUD

1) 确定边界 edges：
- 若 BOX_VALID：edge_low=box_low, edge_high=box_high
- 否则（LADDER_MODE）：edge_low=ladder_low, edge_high=ladder_high

2) 绝对 EDGE 定义（防止“EDGE 过宽”Bug）：
- edge_abs = clamp(max(tol, 80), 80, 160)
- out_abs  = clamp(max(tol, 80), 80, 200)
- watch_abs = clamp(2*edge_abs, 160, 320)   // 仅用于“approach key”上锁

zone_calc：
- 若 P < edge_low - out_abs  ⇒ OUT_DOWN
- 否则若 P > edge_high + out_abs ⇒ OUT_UP
- 否则若 abs(P - edge_low)  <= edge_abs ⇒ EDGE_LOW
- 否则若 abs(P - edge_high) <= edge_abs ⇒ EDGE_HIGH
- 否则 ⇒ MID_BOX

3) Mud / 中央禁交易覆盖：
- count_near = #{ ssp_price ∈ SSP | |ssp_price - P| <= 120 }
- 若 zone_calc == MID_BOX 且 (count_near >= 5 或 market.ssp_zone == "BATTLE")：
  ⇒ zone = MUD
- 否则 zone = zone_calc

### C7) Box drift（2 轮持久性；仅 BOX_VALID）
drift2_dir ∈ {UP, DOWN, NONE}，使用最近 3 个 BOX 快照（cur, prev, prev2）：
- drift_1=UP 若 low_cur>low_prev 且 high_cur>high_prev
- drift_1=DOWN 若 low_cur<low_prev 且 high_cur<high_prev
- drift2_dir=UP 若 drift_1=UP 且 low_prev>low_prev2 且 high_prev>high_prev2
- drift2_dir=DOWN 若 drift_1=DOWN 且 low_prev<low_prev2 且 high_prev<high_prev2
回退：若提供 market.ssp_box_drift，则使用之。

### C8) Drift 例外（中心入场）
默认：zone=MUD ⇒ WAIT。
例外：
- zone=MUD 且 drift2_dir=UP ⇒ 允许中心 LONG（仍需 reclaim/hold-side；分形可选）
- zone=MUD 且 drift2_dir=DOWN ⇒ 允许中心 SHORT。

### C9) history_ctx.tags · TAG_OPS 协议（仅增量）
输出 `logic.history_view` 为 TAG_OPS 字符串（仅 delta，不输出全量）：

```
TAG_OPS
+ADD <TAG_STRING>
-DEL <MATCH_EXPR>
~DEDUP <TAG_TYPE>
```

键：
- ARMED_WATCH key = (watch_dir, watch_level)
- EXTENSION_ACTIVE key = (dir, level)

调度器预期：
1) 解析 tags，ttl 递减，过期 ttl<=0
2) 先应用 -DEL，再应用 +ADD，最后 ~DEDUP
3) 将处理后的 active tag 列表作为下一次调用的 history_ctx.tags 回灌

ttl 以调用次数计；调度器应缩放使 ttl=2 覆盖约 60–120 秒市场时间。

## D) 方向规则（C 信号 + Extreme 仅回测 + ARMED_WATCH）

### D1) 基于 C3/C5 的原始方向（`c_dir`）
- C3=UP 且 C5=UP  ⇒ c_dir=LONG
- C3=DOWN 且 C5=DOWN ⇒ c_dir=SHORT
- 否则 ⇒ c_dir=NONE

### D2) EXTREME 三连（`c_extreme`）+ 仅回测（RETEST-ONLY）机械闭环
定义：
- c_extreme=TRUE 当 (C1=C3=C5=UP) 或 (C1=C3=C5=DOWN)，否则 FALSE。
- dir_drive = c_dir（LONG/SHORT）即便 EXTREME；若 c_dir=NONE 则 dir_drive=NONE。

策略（机械化、闭环）：
- 若 c_extreme=TRUE：
  - 本次调用禁用 Pattern-A（干净穿越追单）。
  - 仅允许 Pattern-B（突破后回测）在方向 = dir_drive 上评估入场。
  - 不得从 EXTREME 触发新的 ARMED_WATCH。
  - cand_dir 在常规路由中视为 NONE；Pattern-B 评估直接使用 dir_drive。

### D3) 解析既有 ARMED_WATCH（若存在）
从 history_ctx.tags 中定位最新的 ARMED_WATCH：
- watch_dir ∈ {LONG, SHORT}
- watch_level（数值 SSP）
- ttl
watch_valid = (ttl >= 1)

### D4) 分形偏置失效化（避免陈旧锁定）
从当前快照计算 fractal_bias：
- 若 touch(res) 且 top_fractal(res) ⇒ fractal_bias=SHORT
- 否则若 touch(sup) 且 bottom_fractal(sup) ⇒ fractal_bias=LONG
- 否则若 cross_up(res) 且 hold_above(res) ⇒ fractal_bias=LONG
- 否则若 cross_down(sup) 且 hold_below(sup) ⇒ fractal_bias=SHORT
- 否则 fractal_bias=NONE

若 watch_valid 且 fractal_bias 与 watch_dir 相反：
- 本次调用将 watch 视为无效
- 在 logic.history_view 输出 TAG_OPS：`-DEL TYPE=ARMED_WATCH`（或更具体匹配）

### D5) 候选方向（`cand_dir`）仲裁
- 若 watch_valid 且未被失效化 ⇒ cand_dir = watch_dir
- 否则若 c_extreme=TRUE ⇒ cand_dir = NONE
- 否则 ⇒ cand_dir = c_dir

## E) 结构与趋势过滤（支持，但不专制）

### E1) 输入
使用 struct_ctx.struct_1m/5m/15m：trend + last_swings（HH/HL/LH/LL），若可用。

### E2) 变盘检测（CHOCH 优先；仅基于标签与 swing 价比较）
目的：为顺势入场（Pattern-A）提供“许可信号”，并在真实翻转时放松过滤。
这不是直接入场触发。

令 `sw = struct_1m.last_swings`（按时间顺序）。若缺失 ⇒ shift_ok_1m=FALSE。

计算 `close_1m = last(bars_1m).c` 若 bars_1m 存在，否则 close_1m=P。

对 LONG（熊转牛）：
1) 在 sw 中找到最近的 `LL`，记为 `LL*`。
2) 向前扫描找到 `LL*` 之前最近的 `LH`，记为 `LH*`。
3) 定义 CHOCH_UP = (LH* 存在) 且 (close_1m > LH*.price)。
4) 定义 BOS_UP（更后续）= 最近三个 swing 标签以 LL→HL→HH 结束。
设 shift_ok_1m = CHOCH_UP 或 BOS_UP。

对 SHORT（牛转熊）：
1) 在 sw 中找到最近的 `HH`，记为 `HH*`。
2) 向前扫描找到 `HH*` 之前最近的 `HL`，记为 `HL*`。
3) 定义 CHOCH_DN = (HL* 存在) 且 (close_1m < HL*.price)。
4) 定义 BOS_DN（更后续）= 最近三个 swing 标签以 HH→LH→LL 结束。
设 shift_ok_1m = CHOCH_DN 或 BOS_DN。

若可用，则基于 struct_5m 以同样方式计算 shift_ok_5m；否则为 FALSE。

### E3) 最小方向支持过滤
对 LONG：
- bull_filter_ok = (struct_1m.trend != DOWN) 或 (shift_ok_1m=TRUE)
- 且避免“全周期 DOWN”叠加：当 5m 与 15m 都为 DOWN 且不存在 shift_ok_5m 时，抑制。

对 SHORT：
- bear_filter_ok = (struct_1m.trend != UP) 或 (shift_ok_1m=TRUE)
- 且避免“全周期 UP”叠加：当 5m 与 15m 都为 UP 且不存在 shift_ok_5m 时，抑制。

## F) 2 轮观察窗口（ARMED_WATCH ttl=2）— 严格使用
ARMED_WATCH 仅在以下情形使用：
- APPROACH_KEY：cand_dir 存在，但 abs(P - key_level) 处于 watch_abs 内（<=watch_abs）且尚不可执行（>edge_abs）。
- PENDING_FRACTAL：touch(key_level) 且满足 reclaim/hold-side，但所需分形（顶部/底部）尚未打印。

窗口行为：
- 在 ttl 窗口内：不再要求再次满足 C；一旦入场条件满足，立即开仓。
- 过期（ttl<=0）：watch 失效；不得对同一 (watch_dir, watch_level) 重新上锁，除非 key_level 变化 >= edge_abs 或方向翻转。

禁止堆叠：
- 若已有 watch：直接 WAIT，不得新增更多 watch。

- decision=WAIT, mode=NONE；不得输出新标签。

## H) 模式选择（RANGE_REVERT vs BREAKOUT_FOLLOW）

- 若 cand_dir=NONE ⇒ WAIT（除非 EXTREME 的仅回测路径通过 Pattern-B 开仓）。
- 若 zone=MUD 且无 drift 例外 ⇒ WAIT。
- 若 drift 例外激活（zone=MUD 且 drift2_dir 与方向一致）⇒ mode=BREAKOUT_FOLLOW。

按 zone 的标准映射：
- EDGE_LOW + LONG  ⇒ RANGE_REVERT
- EDGE_HIGH + SHORT ⇒ RANGE_REVERT
- OUT_DOWN + LONG  ⇒ RANGE_REVERT（假跌破后回收）
- OUT_UP + SHORT   ⇒ RANGE_REVERT（假突破后回落）
- OUT_UP + LONG    ⇒ BREAKOUT_FOLLOW
- OUT_DOWN + SHORT ⇒ BREAKOUT_FOLLOW
否则 ⇒ WAIT。

## I) 入场逻辑 — “确认 ⇒ 立刻入场”，含 2 轮 watch 例外

### I1) 原语（优先 bars_1m）
sup = nearest_below_ssp(P, SSP) ; res = nearest_above_ssp(P, SSP)

- touch(level)=TRUE 若最近 3 根 bars 中任一根满足 low <= level <= high
- touched_recent(level)=最近 3 根内出现 touch(level)
- reclaim_up(level)=touched_recent(level) 且最后收盘 >= level
- reclaim_down(level)=touched_recent(level) 且最后收盘 <= level

Cross/hold 辅助（需要 bars_1m >=2，否则回退到 close vs level）：
- prev_close = bars_1m[-2].c 若存在，否则 P
- last_close = bars_1m[-1].c 若存在，否则 P
- cross_up(level)= (prev_close < level) 且 (last_close >= level)
- cross_down(level)= (prev_close > level) 且 (last_close <= level)
- hold_above(level)= (last_close >= level) 且 (min(最近 2 次收盘) >= level - tol 若 bars_1m>=2 否则 TRUE)
- hold_below(level)= (last_close <= level) 且 (max(最近 2 次收盘) <= level + tol 若 bars_1m>=2 否则 TRUE)

分形（质量增强；除 EXTREME 仅回测路径外可选）：
- top_fractal(level)=TRUE 若 1m 结构确认在/近 level 的 swing high
- bottom_fractal(level)=TRUE 若 1m 结构确认在/近 level 的 swing low

### I2) 关键位选择（`key_level`）
对 cand_dir=LONG：
- 若 mode=RANGE_REVERT：优先 key_level = edge_low，否则 sup
- 若 mode=BREAKOUT_FOLLOW：优先 key_level = edge_high，否则 res

对 cand_dir=SHORT：
- 若 mode=RANGE_REVERT：优先 key_level = edge_high，否则 res
- 若 mode=BREAKOUT_FOLLOW：优先 key_level = edge_low，否则 sup

定义：
- dist_key = abs(P - key_level)
- actionable = (dist_key <= edge_abs)

### I3) FAST_ENTRY（主要行为）— 可执行即开仓
当且仅当以下全部为 true，fast_entry_ok=1：
- cand_dir ∈ {LONG, SHORT}
- mode ∈ {RANGE_REVERT, BREAKOUT_FOLLOW}
- zone 不在 {MID_BOX, MUD}（MUD 仅允许通过 I5 drift 例外）
- actionable=TRUE
- 方向过滤通过：
  - LONG => bull_filter_ok
  - SHORT => bear_filter_ok
- close-side 条件（必须满足）：
  RANGE_REVERT：
    - LONG：reclaim_up(key_level) 或 (touch(key_level) 且 last_close >= key_level)
    - SHORT：reclaim_down(key_level) 或 (touch(key_level) 且 last_close <= key_level)
  BREAKOUT_FOLLOW：
    - LONG：(cross_up(key_level) 且 hold_above(key_level)) 或 hold_above(key_level)
    - SHORT：(cross_down(key_level) 且 hold_below(key_level)) 或 hold_below(key_level)

FAST_ENTRY 的 setup 名称：
- FAST_REVERT_EDGE_LOW_RECLAIM
- FAST_REVERT_EDGE_HIGH_RECLAIM
- FAST_BREAKOUT_HOLD_ABOVE
- FAST_BREAKOUT_HOLD_BELOW

若 fast_entry_ok=1：
- decision = cand_dir
- 输出 EXTENSION_ACTIVE
- 分形是否存在需记录在 logic 中，但不作为必须条件。

### I4) WATCH 例外（仅在 fast_entry_ok=0 时）
若 fast_entry_ok=0 且 cand_dir 存在且当前无 active watch：
A) PENDING_FRACTAL 上锁：
- touched_recent(key_level)=TRUE
- close-side 条件满足（同 I3）
- 但缺少所需分形：
  - LONG（低位回归 / 回测支撑）：bottom_fractal(key_level)=FALSE
  - SHORT（高位回归 / 回测压力）：top_fractal(key_level)=FALSE
=> 输出 +ADD ARMED_WATCH watch_dir=cand_dir watch_level=key_level ttl=2；并 WAIT

B) APPROACH_KEY 上锁：
- dist_key <= watch_abs 且 dist_key > edge_abs
=> 输出 +ADD ARMED_WATCH watch_dir=cand_dir watch_level=key_level ttl=2；并 WAIT

若已存在 active watch：
- 使用 watch_level 作为 key_level_override 再评估 fast_entry_ok：
  key_level = watch_level
  actionable = abs(P - key_level) <= edge_abs
- 一旦 fast_entry_ok 变为 1，或缺失分形打印且 close-side 条件仍成立：
  => 立即入场。
- 否则 WAIT，且不得新增标签。

### I5) Drift 中心例外（仅此处允许 MUD / MID）
若 drift2_dir=UP：允许中心 LONG，当：
- cand_dir=LONG
- touch(sup) 且 (reclaim_up(sup) 或 last_close>=sup) 且 bull_filter_ok
- dist_key<=edge_abs，其中 key_level=sup
分形可选。

若 drift2_dir=DOWN：允许中心 SHORT，当：
- cand_dir=SHORT
- touch(res) 且 (reclaim_down(res) 或 last_close<=res) 且 bear_filter_ok
- dist_key<=edge_abs，其中 key_level=res
分形可选。

### I6) 迟到追单护栏（避免“末端追涨杀跌”）
若 1m last_swings 显示较长的交替链（例如 >=7 个 pivot），且最近结构暗示走势已偏晚：
- 在 logic 中降低 BREAKOUT_FOLLOW 质量评价，但若 actionable+hold-side 强，则不阻断 FAST_ENTRY。
- 对 EXTREME 仅回测：仍只允许 Pattern-B。

### I7) confirm_ok + setup
当任一可用路径成立时 confirm_ok=1：
- FAST_ENTRY（I3）> Drift center（I5）> EXTREME Pattern-B
否则 confirm_ok=0 且 setup=NONE。

EXTREME Pattern-B（精神不变，仍更严格）：
- 仅当 c_extreme=TRUE 且 dir_drive!=NONE
- 需要回测结构：
  LONG：从上方触碰 edge_high/res 且 reclaim_up 且 bull_filter_ok（分形可选）
  SHORT：从下方触碰 edge_low/sup 且 reclaim_down 且 bear_filter_ok（分形可选）

## J) 决策树（无死循环）
1) 计算 context、zone、edges、S0/R0、sup/res、tol、drift2_dir、edge_abs/watch_abs。
2) 计算 c_dir + c_extreme；解析 ARMED_WATCH；必要时失效化陈旧 watch（输出 -DEL）。
3) 确定 cand_dir（watch > extreme > c_dir）。
4) 应用 EXTENSION_ACTIVE 护栏。
5) 若 cand_dir=NONE：
   - 若 c_extreme=TRUE：用 dir_drive 评估 EXTREME Pattern-B；否则 WAIT。
6) 从 zone 选择可用 mode。
7) 评估 fast_entry_ok（I3）。若为 1 ⇒ 入场。
8) 否则评估 drift center（I5）与（如适用）EXTREME Pattern-B。
9) 否则：
   - 若无 active watch 且 c_dir!=NONE 且 c_extreme=FALSE：仅按 F/I4（APPROACH_KEY 或 PENDING_FRACTAL）上锁 watch。
   - 否则 WAIT 且不更新标签。

---

## K) TP/SL 规则（原则一致）

### K1) 止损（SL）
优先采用基于 SSP 的结构止损：
- LONG：在支撑（S0 / edge_low / key_level）下方减去 tol 缓冲
- SHORT：在压力（R0 / edge_high / key_level）上方加上 tol 缓冲

回退硬止损：
- LONG：sl_zone = P - 300
- SHORT：sl_zone = P + 300

### K2) 止盈（TP）
RANGE_REVERT：
- TP1：盒内朝向中部最近的 SSP
- TP2：对侧边界（BOX_VALID）否则为下一阶 ladder 档位

BREAKOUT_FOLLOW：
- TP1：顺势方向下一档 SSP（LONG=>R1；SHORT=>S1）
- TP2：若存在则取下下档 SSP，否则 TP1 ± 300（按方向）

## L) logic.* 内容要求（中文）
- c_signal：说明 c_dir / cand_dir 来源；若触发 EXTREME+仅回测需注明。
- ssp_view：列出关键 SSP 价位、edges、zone、S0/R0；展示 1–2 个密度最高的 level。
- kline_1m：说明触发了哪个 setup（FAST_ENTRY / DRIFT_CENTER / EXTREME_RETEST）以及 reclaim/hold-side 证据。
- kline_struct：报告 bull_filter_ok / bear_filter_ok，以及 shift_ok_1m 属于 CHOCH 还是 BOS。
- history_view：仅输出 TAG_OPS 增量；否则输出“(无标签更新)”。
- tp_sl_rule：解释 TP/SL 的选择与回退逻辑。
- summary：一行中文总结：zone/context → 方向来源 → 立即触发（reclaim/hold）或 watch 原因 → mode → TP/SL。

entry_zone 字符串格式：
- "KEY=<level>;SETUP=<setup>;SIDE=<RECLAIM_UP|RECLAIM_DN|HOLD_ABOVE|HOLD_BELOW|WATCH_PENDING_FRAC|WATCH_APPROACH>"

## M) 最终自检（输出前）
- JSON schema 有效；键名与 Output Contract 完全一致。
- WAIT => mode=NONE, sl_zone=0, tp_zone=[]。
- LONG/SHORT => tp_zone 必须恰好 2 个元素。
- EXTREME => 禁用 Pattern A；不得新增 ARMED_WATCH。
- ARMED_WATCH 仅用于 APPROACH_KEY 或 PENDING_FRACTAL 且严格 ttl=2。
- history_view 仅为 TAG-DELTA（不得复述全量标签）。
